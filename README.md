# Web Development Portfolio

This is a personal portfolio website designed to showcase my web development projects, skills, and contact information. It includes sections for my featured skills, projects, and a way to download my CV.

Features

- Responsive Design: The website is fully responsive and works seamlessly on all devices.
- Projects Section: Highlights my latest web development projects.
- Skills Section: Displays my expertise in web development and design.
- Contact Section: Provides ways to reach me, including a downloadable CV.
- Social Media Links: Follow me on LinkedIn, X (formerly Twitter), WhatsApp, and Facebook.

## Technologies Used

- HTML5: For structuring the content.
- CSS3: For styling the website.
- Bootstrap 5: For responsive design and layout.
- Font Awesome: For icons used in the navigation and footer.

## How to Use

1. Clone the repository to your local machine:
